# eduplatform 기획서

우리가 "무엇을" 만들었는지 정리한 문서. 초기 MVP 기획을 담았던 이전 버전에서, 지금까지 실제로
구현·배포된 최종 산출물 기준으로 갱신했다. 기술 설계는 [DESIGN.md](DESIGN.md), 실제 완성된 산출물
목록은 [DELIVERABLE.md](DELIVERABLE.md), 개발 진행 규칙과 세션별 작업 이력은 [../CLAUDE.md](../CLAUDE.md) 참고.

---

## 1. 한 줄 정의

> 초등학생과 성인이 **영어 입문부터 단계별 로드맵을 따라** 듣기·말하기·읽기·쓰기를 종합적으로
> 학습하고, 개인의 약점 영역에 맞춘 코스로 스스로를 관리해 나가는 웹 학습 플랫폼.

## 2. 타겟 사용자

| 유형 | 대상 | 특성 |
|------|------|------|
| 초등학생(CHILD) | 영어를 처음 접하는 어린이 | 쉬운 UI, 짧은 레슨, 마스코트 인사말, 그림 중심 콘텐츠 |
| 성인(ADULT) | 기초부터 다시 시작하는 성인 | 실용 표현, 밀도 있는 레슨, 격식 있는 문장 |

두 유형 모두 **입문(BEGINNER)** 부터 시작해 초급·중급·고급까지 로드맵을 따라 올라간다.

## 3. 핵심 컨셉

### 3-1. 종합형 학습 (4대 영역 + 어휘)

레슨은 하나의 주제를 **듣기·말하기·읽기·쓰기**로 두루 다룬다.

| 활동 유형 | 학습자가 하는 것 | 실제 구현 |
|-----------|------------------|-----------|
| 어휘(VOCAB) | 단어·뜻·예문 익히기, 빈칸 채우기 퀴즈 | 텍스트 플래시카드 + 문장 안 핵심 단어 빈칸 퀴즈 |
| 읽기(READING) | 짧은 지문 읽고 이해 | 텍스트 플래시카드 |
| 쓰기(WRITING) | 문장 완성·베껴쓰기 | 텍스트 플래시카드 |
| 듣기(LISTENING) | 오디오 듣고 이해 | 브라우저 내장 TTS(`speechSynthesis`)로 문장 재생 |
| 말하기(SPEAKING) | 문장 따라 말하기 | TTS로 듣기 + 브라우저 음성인식(`SpeechRecognition`)으로 실제 발화를 인식해 정답/오답 확인 |

**차별점**: 한 영역만이 아니라, 대상·레벨 8개 조합(초등/성인 × 4레벨) 전부에 5개 영역이 고르게
채워져 있다 — 공식 코스 49개, 레슨 343개.

### 3-2. 공식 코스 + 개인 맞춤 코스

불특정 다수를 위한 오픈 카탈로그가 아니라, **개개인의 약점 영역에 맞춘 학습**을 지향한다.

- **공식 코스**: 레벨(BEGINNER~ADVANCED) 기준으로 구성되는 기본 제공 코스.
- **개인 코스**: 회원별로 "듣기·말하기·읽기·쓰기·어휘 중 어디에 비중을 둘지" 기준으로 구성되는 맞춤
  코스. 공식 코스에서 해당 영역 레슨만 골라 복사해 담는다(레슨을 여러 코스가 공유하지 않음).

개인 코스의 비중 기준은 세 가지 방식 모두 구현을 완료했고, 회원이 원하는 방식을 그때그때 고를 수 있다.

1. **자가 선택(SELF_SELECTED)** — 회원이 직접 약한 영역을 체크박스로 선택.
2. **학습 이력 기반(HISTORY_BASED)** — 영역별 완료 커버리지가 가장 낮은 영역을 자동 추천(완료
   레슨 3개 미만이면 근거 부족으로 안내).
3. **진단 테스트(DIAGNOSTIC_TEST)** — 대상·레벨별 10문항을 풀어 정답률이 가장 낮은 영역을 산출
   (전체 80문항 시드, 관리자 화면에서 문항 추가 가능).

### 3-3. 체계적 레벨 / 로드맵

```
BEGINNER(입문) → ELEMENTARY(초급) → INTERMEDIATE(중급) → ADVANCED(고급)
   └ 코스 → 레슨(활동들) → 완료 → 다음 레슨/코스 자동 안내
```

- 학습자는 자기 레벨의 로드맵을 순서대로 밟고, 진도율로 위치를 파악한다.
- 코스를 전부 완료하면 상세 화면에 다음 로드맵 코스를 자동으로 안내한다.
- 레벨을 스스로 정하기 어려운 신규 회원을 위해 가입 화면에 간단 배치 테스트(8문항)를 별도로 뒀다.

### 3-4. 반복해서 돌아오게 만드는 장치

한 번 학습하고 끝나는 게 아니라, 다시 찾아올 이유를 여러 각도로 마련했다.

- **학습 스트릭**(연속 학습일)과 **월간 활동 캘린더**로 꾸준함을 시각화.
- **간격 반복 복습** — 완료한 지 3일 지난 레슨을 자동으로 다시 추천하고, 헤더에 복습 대상 개수를
  배지로 노출.
- **그림 퀴즈**(비회원도 가능)·**매일매일 단어장/단어 퀴즈**로 매일 새로운 문제를 결정론적으로 생성.
- **코스 즐겨찾기**로 관심 코스를 모아보고, **코스 평점·후기**로 다른 학습자의 선택을 참고.

## 4. 범위 (Scope)

### 최종 구현 범위

처음 MVP로 정의했던 "회원가입/로그인 + 코스·레슨 학습(텍스트) + 진도 표시"를 넘어, 아래 전 범위를
실제로 구현·검증했다(카테고리별 상세 목록은 [DELIVERABLE.md](DELIVERABLE.md) 참고).

1. **계정/보안** — 이메일 인증 회원가입, 로그인/로그아웃, 레벨 배치 테스트, 프로필 관리(닉네임·
   레벨·비밀번호 변경), 비밀번호 찾기, 회원 탈퇴, 로그인 시도 제한(계정 잠금), 비회원 콘텐츠 열람
   제한(코스별 첫 레슨만 공개), 보안 응답 헤더(CSP·HSTS·Referrer-Policy·Permissions-Policy).
2. **학습 콘텐츠** — 5대 영역이 전부 채워진 공식 코스 49개·레슨 343개, 코스/레슨 목록·상세·검색
   (제목·설명·레슨 본문), 레슨 내 이해도 확인 퀴즈, 실제 음성인식 말하기 연습, 코스 완료 시 다음
   코스 자동 안내.
3. **개인화** — 개인 코스 3가지 기준(자가선택/학습이력기반/진단테스트, 80문항).
4. **동기부여** — 마이페이지 대시보드(진도율·영역별 진도), 학습 스트릭, 월간 활동 캘린더, 간격
   반복 복습 + 알림 배지, 그림 퀴즈, 매일 단어장/단어 퀴즈, 코스 즐겨찾기, 코스 평점·후기.
5. **관리자** — 코스/레슨 CRUD·순서 재배치, 진단 테스트 문항 관리, 회원 목록·역할 관리, 콘텐츠
   커버리지 대시보드(대상×레벨×영역 조합별 콘텐츠 현황 한눈에 확인).
6. **UX/접근성** — 반응형 모바일 대응, 다크모드(시스템 연동+수동 토글), 웹 접근성(스크린리더용
   fieldset/legend, 스킵 링크, 색 대비 검증).

### 이번엔 안 함 (Out of Scope, 유지)

- 결제/구독, 실시간 화상 수업, 커뮤니티/채팅, 모바일 앱(네이티브).
- 리뷰 신고·관리자 리뷰 삭제, 회원 강제 탈퇴(관리자가 다른 회원 계정을 대신 삭제) — 필요해지면
  후속 작업으로.

### 의도적으로 미룬 것

- **마스코트 캐릭터 이미지** — SVG로 직접 그려본 시도가 기대에 못 미쳐 보류. 사용자가 이미지
  파일을 전달하면 그때 연결.
- **운영 DB 전환·배포** — 콘텐츠·기능 개발이 우선순위였던 동안 의도적으로 최후순위로 미룸(지금은
  H2 인메모리 DB로 매 재시작마다 샘플 데이터를 새로 시딩하는 개발 구성).

## 5. 화면 흐름

```
회원가입(이메일 인증) / 로그인
      ↓
내 레벨 로드맵(코스 목록, 검색·필터)  →  코스 상세(레슨 목록, 평점·리뷰, 즐겨찾기)  →  레슨 학습(활동+퀴즈)
      ↑___________________________ 완료 시 진도·스트릭·캘린더 갱신 _________________________↓
      마이페이지(대시보드, 개인 코스, 즐겨찾기, 복습, 매일 단어장)
```

관리자는 별도로 `/admin` 대시보드에서 콘텐츠 커버리지를 확인하고, 코스·레슨·문항·회원을 관리한다.

## 6. 성공 기준

MVP 단계에서 정의했던 기준을 그대로 충족했고, 그 위에 재방문·개인화 지표까지 갖췄다.

- ✅ 신규 사용자가 가입 → 자기 레벨 코스를 골라 → 레슨을 끝까지 학습하고 → 진도가 기록된다.
- ✅ 초등/성인 각 4개 레벨 전부에 5대 영역 샘플 코스·레슨이 채워져 있다(대상×레벨×영역 커버리지
  갭을 관리자 대시보드로 상시 확인 가능).
- ✅ 회원이 자기 약점 영역에 맞는 개인 코스를 3가지 방식 중 하나로 스스로 만들 수 있다.
- ✅ 학습을 며칠 쉬어도 스트릭·복습 알림·캘린더가 다시 돌아올 이유를 제공한다.

## 7. 열린 질문 (모두 해결됨)

기획 초기에 열어뒀던 질문들은 개발을 진행하며 아래처럼 전부 결정·구현했다.

- ~~레벨 판정: 가입 시 자가 선택 vs 간단한 레벨 테스트?~~ → 둘 다 제공(자가 선택 + 8문항 배치
  테스트).
- ~~오디오 소스: 자체 녹음 vs TTS?~~ → 브라우저 내장 `speechSynthesis`(TTS)로 결정.
- ~~말하기 평가: 발음 점수화 범위와 방식?~~ → 점수화 없이 `SpeechRecognition`으로 인식한 텍스트를
  목표 문장과 정규화 후 완전 일치로만 비교(정답/오답 이분법).
- ~~레벨 판정 이후에도 "다음에 뭘 배워야 할지" 안내가 필요하지 않을까?~~ → 코스 완료 시 로드맵상
  다음 코스를 자동으로 추천.
- ~~한 번 배운 걸 잊어버리지 않게 하려면?~~ → 3일 경과 완료 레슨을 복습 대상으로 자동 추천 +
  헤더 배지로 노출.

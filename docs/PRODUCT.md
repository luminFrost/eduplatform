# eduplatform 기획 정의서

우리가 "무엇을" 만들 것인지 정의한 문서. 개발 방향의 기준점.
기술 설계는 [DESIGN.md](DESIGN.md), 개발 진행 규칙은 [../CLAUDE.md](../CLAUDE.md) 참고.

---

## 1. 한 줄 정의

> 초등학생과 성인이 **영어 입문부터 단계별 로드맵을 따라** 듣기·말하기·읽기·쓰기를
> 종합적으로 학습하는 웹 플랫폼.

## 2. 타겟 사용자

| 유형 | 대상 | 특성 |
|------|------|------|
| 초등학생(CHILD) | 영어를 처음 접하는 어린이 | 쉬운 UI, 짧은 레슨, 그림·음성 |
| 성인(ADULT) | 기초부터 다시 시작하는 성인 | 실용 표현, 밀도 있는 레슨 |

두 유형 모두 **입문(BEGINNER)** 부터 시작. 대상·레벨에 맞는 코스를 제공한다.

## 3. 핵심 컨셉 — 종합형 학습 + 체계적 로드맵

### 3-1. 종합형 학습 (4대 영역 + 어휘)

레슨은 하나의 주제를 **듣기·말하기·읽기·쓰기**로 두루 다룬다. 각 레슨은 여러 활동으로 구성된다.

| 활동 유형 | 학습자가 하는 것 | 기술 요건 |
|-----------|------------------|-----------|
| 어휘(VOCAB) | 단어·뜻·예문 익히기, 복습 | 텍스트 (가벼움) |
| 읽기(READING) | 짧은 지문 읽고 이해 | 텍스트 |
| 쓰기(WRITING) | 문장 완성·작문 후 제출 | 텍스트 입력 |
| 듣기(LISTENING) | 오디오 듣고 문제 풀기 | 오디오 파일/TTS |
| 말하기(SPEAKING) | 문장 따라 말하기 | 마이크·음성인식 |

> **차별점**: 한 영역만이 아니라, 한 레슨 안에서 4대 영역을 균형 있게 다룬다.

### 3-2. 공식 코스 + 개인 맞춤 코스

이 플랫폼은 불특정 다수를 위한 오픈 서비스가 아니라, **개개인의 특징(약점 영역)에 맞춘 학습**을 지향한다.

- **공식 코스**: 레벨(BEGINNER~ADVANCED) 기준으로 구성되는 기본 제공 코스.
- **개인 코스**: 회원별로 "듣기·말하기·읽기·쓰기 중 어디에 비중을 둘지" 기준으로 구성되는 맞춤 코스.
  공식 코스와 동일한 코스/레슨 구조를 그대로 쓰며, 화면·진도 추적도 공유한다 (레슨을 여러 코스가 공유하진 않음 — 개인 코스의 레슨은 새로 만들거나 복사해서 구성).

개인 코스의 비중 기준은 다음 세 가지 방식으로 정할 수 있고, 회원이 원하는 방식을 고른다. 구현은 아래 순서로 단계적으로 (③이 최후순위):

1. **자가 선택(SELF_SELECTED)** — 회원이 직접 약한 영역을 선택. 우선 구현.
2. **학습 이력 기반(HISTORY_BASED)** — 진도·정답률 데이터가 쌓인 뒤 시스템이 자동 판단.
3. **진단 테스트(DIAGNOSTIC_TEST)** — 별도 테스트 문항을 풀어 산출. 구현 우선순위 최하.

### 3-3. 체계적 레벨 / 로드맵 (핵심 차별화)

학습자가 "다음에 뭘 해야 할지" 항상 명확하도록 **단계별 로드맵**을 제공한다.

```
BEGINNER(입문) → ELEMENTARY(초급) → INTERMEDIATE(중급) → ADVANCED(고급)
   └ 코스 → 레슨(활동들) → 완료 → 다음 레슨/코스 자동 안내
```

- 각 레벨은 여러 코스로, 코스는 순서가 있는 레슨으로 구성.
- 학습자는 자기 레벨의 로드맵을 따라 순차 진행, 진도율로 위치를 파악.

## 4. 범위 (Scope)

### MVP (1차 목표) — 반드시 만든다

1. **회원가입/로그인** — 이메일 기반, 초등/성인 유형 및 시작 레벨 선택.
2. **코스·레슨 학습** — 레벨별 코스 목록 → 코스 상세(레슨 목록) → 레슨 학습 화면.
   - MVP 레슨 활동은 **텍스트 기반(어휘·읽기·쓰기)** 부터 구현.
3. **로드맵/진도의 기본** — 레슨 완료 체크와 진도 표시(체계적 진행의 최소형).

### MVP 이후 (Phase 2+)

- 듣기(오디오/TTS), 말하기(음성인식) 활동 — 종합형 완성.
- 퀴즈/테스트, 복습(간격 반복).
- 개인 맞춤 코스: 자가 선택 → 학습 이력 기반 → 진단 테스트 순으로 구현 (3-2 참고).
- 대상·레벨별 추천, 학습 대시보드.
- 인증 강화(Spring Security), 운영 DB 전환, 배포.

### 이번엔 안 함 (Out of Scope)

- 결제/구독, 실시간 화상 수업, 커뮤니티/채팅, 모바일 앱.

```
      ↑___________________ 완료 시 진도 갱신 ________________↓
      마이페이지(진도율)
```

## 6. 성공 기준 (MVP)

- 신규 사용자가 가입 → 자기 레벨 코스를 골라 → 레슨을 끝까지 학습하고 → 진도가 기록된다.
- 초등/성인 각각 최소 1개 레벨의 샘플 코스·레슨이 채워져 있다.

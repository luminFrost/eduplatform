# eduplatform 산출물

지금까지 실제로 구현·검증을 마치고 `main` 브랜치에 병합된 기능 전체를 정리한 문서. "무엇을 만들
것인가"는 [PRODUCT.md](PRODUCT.md), "어떻게 만들었는가"는 [DESIGN.md](DESIGN.md) 참고. 이 문서는
그 결과로 "실제로 무엇이 완성됐는가"에 집중한다. 기능별 구현 배경·검증 과정의 상세 기록은
[../CLAUDE.md](../CLAUDE.md)의 "작업 상태 / 다음 단계" 이력에 남아 있다.

---

## 1. 개요

- **프로젝트**: 초등학생·성인 대상 영어 학습 웹 플랫폼 (Spring Boot 모놀리스)
- **개발 방식**: Claude Code와의 반복 세션으로 기능 단위 계획(EnterPlanMode) → 구현 → 단위/통합
  테스트 → 실서버(curl·브라우저) 검증 → 문서화 → 커밋의 사이클을 매 기능마다 반복.
- **브랜치 전략**: `feature/*` → `dev`(개발 통합) → `main`(배포). 이 문서 시점 기준 `main`에는
  아래 전 기능이 병합돼 있다.

## 2. 핵심 수치

| 항목 | 수치 |
|------|------|

## 3. 기능 목록

### A. 계정 · 인증 · 보안

- **이메일 인증 회원가입** — 폼 제출 시 인증번호를 발급(로그에 출력)하고, 올바른 코드를 입력해야
  실제 계정이 생성된다. 즉시 가입되던 이전 경로는 완전히 제거해 인증 우회를 막았다.
- **로그인 / 로그아웃**, **레벨 배치 테스트**(8문항, 레벨을 모르는 신규 회원용).
- **프로필 관리** — 닉네임·레벨 변경, 비밀번호 변경(현재 비밀번호 확인).
- **비밀번호 찾기** — 이메일로 재설정 링크 발급(로그 출력), 30분 유효 1회용 토큰.
- **회원 탈퇴** — 비밀번호 재확인 후 계정과 학습 진행 기록·개인 코스(레슨 포함)를 함께 삭제,
  관리자 계정은 자기 자신을 탈퇴시킬 수 없도록 방어.
- **로그인 시도 제한** — 5회 연속 실패 시 15분 계정 잠금(인메모리 추적).
- **비회원 콘텐츠 제한** — 로그인하지 않은 사용자는 각 코스의 첫 번째 레슨만 열람 가능, 이후
  레슨은 회원가입 유도 화면으로 대체.
- **보안 응답 헤더** — Content-Security-Policy, Referrer-Policy, Permissions-Policy, HSTS를
  전 페이지에 적용(H2 콘솔만 CSP 예외).
- **역할 기반 인가** — 일반 회원(USER)/관리자(ADMIN) 구분, `/admin/**` 전체를 관리자 전용으로 보호.

### B. 학습 콘텐츠 (코스 · 레슨)

- **공식 코스 카탈로그** — 대상(초등/성인) × 레벨(입문~고급) 8개 조합 전부에 어휘·읽기·쓰기·듣기·
  말하기 5대 영역이 채워진 코스를 제공.
- **코스 목록/상세** — 대상·레벨·영역 필터, 제목·설명·**레슨 본문까지 포함한** 키워드 검색(검색
  결과에서 매칭된 문장 스니펫과 함께 레슨으로 바로 이동 가능).
- **레슨 학습 화면** — `INTRO:`/"영어 — 한국어" 컨벤션으로 파싱된 플래시카드, 아이콘 이미지
  (OpenMoji), 이전/다음 레슨 이동.
- **레슨 내 이해도 확인 퀴즈** — PHRASE 문장에서 핵심 단어를 빈칸으로 만들어 4지선다로 확인,
  정답이어야 "학습 완료" 처리(새 문항 데이터 없이 기존 콘텐츠에서 즉석 생성).
- **듣기/말하기 실습** — 브라우저 TTS로 문장 재생, 말하기는 실제 음성인식으로 발화를 텍스트화해
  목표 문장과 비교.
- **코스 완료 자동 안내** — 코스를 모두 마치면 로드맵상 다음 코스를 자동으로 추천.

### C. 개인화

- **개인 코스 생성** — 대상·레벨이 같은 공식 코스에서 선택한 영역의 레슨만 복사해 담는다.
- **비중 기준 3가지**: 자가 선택(체크박스), 학습 이력 기반(영역별 완료 커버리지가 가장 낮은
  영역 자동 추천), 진단 테스트(10문항 채점).
- 이미 같은 영역 조합의 개인 코스가 있으면 새로 만들지 않고 기존 코스를 재사용(중복 방지).

### D. 동기부여 · 참여

- **학습 대시보드**(`/my`) — 완료 레슨 수·학습 중인 코스 수·전체 진도율, 영역별 진도 막대.
- **학습 스트릭** — 연속 학습일 계산(하루 유예 포함), 대시보드에 🔥 표시.
- **월간 활동 캘린더** — 이번 달 학습량을 날짜별 색 농도로 시각화.
- **간격 반복 복습** — 완료한 지 3일 지난 레슨을 자동으로 다시 추천(`/my/review`), 헤더의
  "마이페이지" 링크에 오늘 복습 대상 개수를 배지로 표시.
- **그림 퀴즈**(`/quiz/picture`, 비회원도 가능) — 초등 코스의 아이콘·단어 쌍으로 매일 새로운
  5문제를 결정론적으로 생성.
- **매일 단어장 / 단어 퀴즈**(`/my/daily`) — 회원 레벨에 맞는 오늘의 단어 5개 + 빈칸 퀴즈.
- **코스 즐겨찾기** — 관심 코스를 토글로 저장, 마이페이지에서 모아보기.
- **코스 평점 · 후기** — 1~5점 별점과 짧은 후기(회원당 코스 하나, 재작성 시 갱신), 코스 목록·
  상세에 평균 평점 배지로 노출.

### E. 관리자 도구

- **콘텐츠 커버리지 대시보드**(`/admin`) — 대상×레벨×영역 조합별 레슨 수·문항 수를 표로 확인,
  빈 칸은 색으로 강조.
- **코스 관리** — 생성·수정, 레슨 목록에서 레슨 생성·수정·삭제·**위/아래 순서 재배치**.
- **진단 테스트 문항 관리** — 4지선다 문항 생성·수정·삭제, 대상·레벨·영역 필터.
- **회원 관리** — 이메일·닉네임 검색, 역할(USER/ADMIN) 승격·강등(자기 자신은 대상에서 제외).

### F. UX · 접근성

- **반응형 모바일 대응** — 뷰포트 메타 태그, 좁은 화면에서 가로 스크롤 없는 레이아웃.
- **다크모드** — 시스템 설정 자동 연동 + 헤더 수동 토글, `localStorage`로 유지.
- **웹 접근성(a11y)** — 퀴즈 라디오 그룹에 `fieldset`/`legend`, 스킵 링크, 폼 요소 `aria-label`,
  표 `scope`, 라이트/다크 색 대비 WCAG 기준 검증.

## 4. 기술 스택 요약

Java 21 · Spring Boot 4.1.0 · Spring Security 7.1.0 · Spring Data JPA(Hibernate 7.4) · Thymeleaf ·
H2(인메모리) · Gradle 9.5.1 · Lombok. 클라이언트 JS는 프레임워크 없이 바닐라 2개 파일(TTS/음성인식,
다크모드 토글)만 사용하고 AJAX는 쓰지 않는다(모든 상호작용이 서버 렌더링 폼 제출). 상세 아키텍처는
[DESIGN.md](DESIGN.md) 참고.

## 5. 테스트 현황

- 단위 테스트(Mockito) — 서비스 레이어 비즈니스 로직 전반.
- `@DataJpaTest` — 리포지토리 커스텀 쿼리(검색, 배치 집계, 정렬 등).
- `@SpringBootTest` + MockMvc — 컨트롤러 종단 플로우(회원가입, 로그인, 레슨 완료, 관리자 CRUD 등).
- 매 기능 완료 시 `./gradlew build`로 전체 스위트 통과를 확인하고, 실서버(`scripts/run-dev.sh`)를
  띄워 curl 또는 브라우저로 실제 동작을 재확인하는 것을 표준 검증 절차로 삼았다.

## 6. 실행 방법

```bash
./gradlew build          # 빌드 + 전체 테스트
./gradlew bootRun         # 포그라운드 실행
./scripts/run-dev.sh      # 백그라운드 실행 (로그: build/bootRun.log)
./scripts/stop-dev.sh     # 중지
```

- 앱: http://localhost:8080
- H2 콘솔: http://localhost:8080/h2-console (JDBC URL `jdbc:h2:mem:eduplatform`, user `sa`)
- 관리자 계정: `admin@eduplatform.com` / `Admin1234!` (서버 기동 시 고정 시드)

## 7. 남은 과제

- 마스코트 캐릭터 이미지 연결(사용자가 이미지 파일을 전달하는 대로 진행 예정).
- 운영 DB 전환 및 배포 파이프라인 구성(의도적으로 최후순위로 미룸).
- 리뷰 신고/관리자 삭제, 관리자에 의한 회원 강제 탈퇴 등은 필요성이 확인되면 후속 기능으로 검토.

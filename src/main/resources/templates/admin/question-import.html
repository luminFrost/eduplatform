문항 일괄 등록 (JSON)

targetType · level · lessonType · prompt · option1~4 · correctOptionIndex 필드를 가진 객체의 배열이에요. audioText는 영역이 LISTENING일 때만 채우고, 그 외엔 생략해도 돼요. targetType은 CHILD · ADULT, level은 BEGINNER · ELEMENTARY · INTERMEDIATE · ADVANCED, lessonType은 VOCAB · READING · WRITING · LISTENING · SPEAKING 중 하나(대문자)여야 하고, correctOptionIndex는 정답 보기의 위치(0~3)예요. 예시: 

[
  {
    "targetType": "ADULT",
    "level": "BEGINNER",
    "lessonType": "VOCAB",
    "prompt": "다음 중 '사과'를 뜻하는 단어는?",
    "option1": "Apple",
    "option2": "Banana",
    "option3": "Grape",
    "option4": "Melon",
    "correctOptionIndex": 0
  }
]

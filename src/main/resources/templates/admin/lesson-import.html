레슨 일괄 등록 (JSON)

title·lessonType·content 필드를 가진 객체의 배열이에요. orderNo는 넣지 않아도 돼요(항상 기존 레슨 뒤에 순서대로 이어붙여요). lessonType은 VOCAB · READING · WRITING · LISTENING · SPEAKING 중 하나(대문자)여야 해요. 예시: 

[
  {
    "title": "1과",
    "lessonType": "VOCAB",
    "content": "INTRO: 🦊 오늘은 인사말을 배워요!\n👋 Hi! — 안녕!"
  },
  {
    "title": "2과",
    "lessonType": "VOCAB",
    "content": "🙋 Hello! — 안녕하세요!"
  }
]
